# Tone Drift Checklist — Grey AI LinkedIn

Use this before approving any generated post. If the content triggers ANY of these, reject or rewrite.

---

## Reject if the content:

1. **Sounds like a whitepaper intro** — "In the evolving landscape of...", "Organizations must consider...", "It is increasingly important to..."

2. **Sounds like a consultant presentation** — neutral, balanced, both-sides framing with no clear opinion

3. **Feels over-explained** — the point is stated, then re-stated, then contextualized, then summarized again

4. **Lacks tension** — nothing in the post makes the reader feel uncomfortable, curious, or challenged

5. **Buries the point** — the actual insight is in paragraph 3 or later, hidden behind setup

6. **Uses long blocks of text** — more than 3 consecutive lines without a break on mobile

7. **Asks a hard-to-answer question** — CTA requires analysis, research, or a multi-sentence response to answer

8. **States observations without consequences** — describes what happened but not why it matters in practice

9. **Sounds neutral when it should sound opinionated** — "This could go either way" instead of "This changes the game for teams that..."

10. **Weakens the first line during final edits** — a strong hook that got softened into something "safer" or more "balanced"

11. **Uses formulaic opener repetition** — same first word or syntactic pattern as the previous 2+ posts

12. **Defaults to binary question CTA** — the last 2+ posts already used binary question CTAs

13. **Contains AI writing tells** — "Additionally," "crucial," "landscape," "highlights," "underscores," "delve," em dash clusters, rule-of-three lists with identical structure

---

## Quick Test

Read the first line out loud. Then ask:

- Would a busy executive stop scrolling?
- Does this sound like a person talking, or a system generating?
- Could this first line apply to any post on any topic? (If yes, it's too generic.)
- Does the post end with something I could answer in 3 seconds?

If any answer is wrong, rewrite before approving.
