# LinkedIn Audit Data

Drop exported XLS/XLSX files from LinkedIn Analytics here.

These files will be used to analyze what's working and what to improve across impressions and engagement.

## Naming Convention

Use date ranges or export dates so we can track trends over time:

```
linkedin-audit-2026-03.xlsx
linkedin-audit-2026-Q1.xlsx
```

## What to export from LinkedIn

- **Post analytics** — impressions, engagement rate, clicks, comments, shares per post
- **Follower demographics** — industry, seniority, location, company size
- **Content performance** — top posts by engagement, by impressions, by clicks
