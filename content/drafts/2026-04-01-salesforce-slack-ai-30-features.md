## HEADLINE
Salesforce shipped 30 AI features for Slack — including making Slackbot an MCP client that can route work to any agent in an enterprise's stack, operating autonomously outside Slack entirely.

## STRATEGY
- Audience: Enterprise technology leaders, product managers, and operations professionals who use Slack and are evaluating agentic AI deployments inside existing enterprise toolchains.
- Current belief: AI features in enterprise collaboration tools are mostly cosmetic — meeting summaries, message drafts, search improvements. Useful, but not transformative.
- Reframe: Slackbot is no longer a chat assistant. It is an agent orchestration layer. An MCP client sitting inside a tool that one million businesses already run means the agentic enterprise is not something you deploy separately — it is something that just arrived inside your existing stack.
- Practical consequence: Any enterprise whose AI strategy is still treating agentic AI as a separate project — not integrated with production tools — is now behind the deployment curve that a million businesses are already running on.
- Core claim: The agentic enterprise is not an emerging paradigm — it shipped to one million companies this week inside the tool they already use for work.
- Tension point: "We're still evaluating agentic AI" and "we use Slack" are now contradictory statements.
- CTA direction: Binary-question (is your AI strategy still treating agents as a separate deployment, or has it caught up with what your collaboration tools just became?)

## KEY FACTS
- 30 new AI features announced; Slackbot upgraded with "reusable AI skills" — autonomous task templates that execute across contexts without human intervention
- Slackbot is now an MCP client: connects and orchestrates with Salesforce Agentforce and any external enterprise agent in the stack
- Agent can now operate outside Slack: monitors desktop activity (deals, calendar, conversations, habits) and makes proactive suggestions
- Marc Benioff: approximately one million businesses running on Slack with 2.5x revenue growth since acquisition
- Source credibility: Named company, production deployment at announced scale (1 million businesses), CEO attribution, live features rolling out over coming months

## GREY AI ANGLE
Slack becoming an MCP client is the most concrete enterprise signal yet that the Model Context Protocol is moving from developer experiment to production enterprise infrastructure. For AI governance teams, this changes the question: it is no longer "should we evaluate agentic AI?" — it is "do we have an identity, permissions, and audit framework for the agent layer that just became active inside our collaboration tools?" AI literacy now includes understanding what MCP means for your organization's existing software stack.
