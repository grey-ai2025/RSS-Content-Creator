## HEADLINE
Adobe launched an AI agent that operates across its entire Creative Cloud suite — Photoshop, Premiere, Lightroom, Illustrator, and more — using natural language commands to execute multi-step creative workflows autonomously. A small team can now describe the creative output it needs and let the agent handle execution across every app.

## STRATEGY
- Audience: Founders, operators, and marketers at 10-50 person companies who currently pay for Adobe subscriptions, hire designers or video editors, or outsource creative production — and who are making decisions about creative team structure.
- Current belief: Adobe is a suite of powerful professional tools that requires trained users to navigate. The value of a designer is not just output — it is knowing which tool to use, in what sequence, with what settings. AI can assist within a single app, but cross-app creative workflows require a human who knows the full system.
- Reframe: Adobe's AI agent does not require you to know which app handles which task. You describe the outcome, and the agent selects the tools, sequences the steps, and executes the workflow across apps. The knowledge barrier that made a trained Adobe user valuable — knowing how to navigate the catalog — is the specific friction the Firefly AI Assistant was designed to remove. A lean team that previously needed a dedicated designer to move between Photoshop, Premiere, and Illustrator can now describe what it needs in plain language and have the agent execute it.
- Practical consequence: The "Creative Skills" feature allows a founder to build a repeatable workflow once — "turn any product photo into formatted social media assets for three platforms" — and trigger it via a single command indefinitely. The extension to Claude's interface means AI agents built on Anthropic can now call Adobe's professional tools as actions, opening automated content pipelines where AI generates, edits, and formats creative work end-to-end.
- Core claim: Adobe's Firefly AI Assistant is the clearest real-world demonstration of what agentic AI looks like in a creative workflow — and it arrives in public beta within weeks, with direct integration to the AI platforms most lean teams are already using.
- Tension point: Adobe's competitive advantage claim is that it is unifying an existing, industry-standard tool catalog — not building new AI features in isolation. But Canva and Figma are building the same agentic workflows. The window in which Adobe's cross-app agent is a differentiator rather than table stakes is narrow.
- CTA direction: Forced Binary (is your current creative production model built on trained users navigating specific tools — or on outcome specification that an agent can execute?)

## KEY FACTS
- Firefly AI Assistant executes "complex, multi-step workflows" across Photoshop, Premiere, Lightroom, Illustrator, Acrobat, and Express using one conversational interface
- "Creative Skills" feature: save repeatable multi-step workflows as a single command — e.g., "social media assets" crops, optimizes, and formats for every platform in one execution
- Third-party integration: Firefly agent features connect to Anthropic Claude and other external LLMs — users can trigger Creative Cloud work from outside Adobe's own ecosystem
- The assistant learns individual user preferences over time (preferred tools, aesthetic choices, workflows) with user-controlled opt-in
- Competitors Canva and Figma are building similar agentic workflows; Adobe claims its advantage is unifying its existing industry-standard tool catalog
- Source credibility: Adobe Inc. — named product launch (Firefly AI Assistant), based on Project Moonlight previewed at Adobe Max October 2025; named company AI chief (Alexandru Costin); entering public beta within weeks of the April 15 announcement

## RAW MATERIAL
Adobe launched the Firefly AI Assistant on April 15 — a unified AI agent operating across Creative Cloud (Photoshop, Premiere, Lightroom, Illustrator, Express, Acrobat) using natural language commands. Based on Project Moonlight (previewed Adobe Max, October 2025), now entering public beta. The "Creative Skills" feature lets users save multi-step repeatable workflows (e.g., "social media assets" crops, optimizes file size, and formats for each platform from one command). Adobe AI chief Alexandru Costin: goal is to "remove some of the friction in learning this large catalog of tools." Third-party integration: Firefly agent features will connect to Anthropic Claude and other external LLMs — users can trigger Creative Cloud workflows directly from Claude's interface. Users retain full control: agent leaves room to interject at any time; sliders and buttons surface for fine-tuning. Competitors Canva and Figma building similar agentic workflows; Adobe claims advantage is unifying existing industry-standard tool catalog.
