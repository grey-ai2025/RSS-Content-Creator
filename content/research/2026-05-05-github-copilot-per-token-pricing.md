## Keyword Match
Service-as-Software / SaaS displacement (Trending Topic #4) — GitHub Copilot's pricing shift from flat subscription to consumption-based billing is a live example of SaaS pricing models breaking down under AI's real cost structure.

## Summary
Starting June 1, 2026, GitHub Copilot will replace its flat-rate "Premium Requests" subscription model with per-token billing, aligning with pricing structures used by Anthropic and OpenAI. The Copilot Pro plan remains at $10/month but now provides 1,000 AI Credits (each worth one cent), with token consumption varying by model complexity, context window, and feature type. Basic code completions and Next Edit Suggestions remain free, but AI-intensive tasks — long codebase analysis, complex agent workflows — will consume credits faster than most users anticipate. A 10,000-word codebase loaded into context uses roughly 12,000-13,000 tokens just for input. For teams using Copilot heavily in agent workflows, monthly costs could exceed the flat rate significantly.

## Key Data Points
- Change effective: June 1, 2026
- Copilot Pro remains $10/month but now provides 1,000 AI Credits instead of a query allotment
- 1 AI Credit = $0.01; token usage varies by model, context, and feature
- A 10,000-word code file = roughly 12,000–13,000 tokens in context (input tokens only)
- Basic code completions and Next Edit Suggestions remain free under new model
- Complex tasks: multi-step agent workflows, large codebase analysis, and extended context operations consume credits rapidly
- Shift mirrors Anthropic's and OpenAI's API pricing — moving AI tool pricing from predictable subscription to variable consumption
- Reports already circulating that some companies have exhausted annual AI budgets mid-year due to agent workflow intensity

## Why It Matters
For any founder or team lead running a development team with Copilot, this is a direct budget change. The flat monthly fee is disappearing — replaced by a model where the more you rely on AI (especially in agent workflows), the more you pay. This is the SaaS-to-Service-as-Software transition happening at the tool level: per-seat pricing is giving way to per-outcome billing. Teams that have budgeted $10/user/month for Copilot need to re-model their AI tool spend against actual usage patterns before June 1. The deeper signal: every major AI tool will eventually make this pricing shift, and the SMBs that don't monitor consumption will get surprised by the bill.
