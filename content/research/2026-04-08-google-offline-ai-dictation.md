# Google Quietly Launches Offline AI Dictation App Built on On-Device Gemma Models

**Title:** Google quietly launched an AI dictation app that works offline

**Source URL:** https://techcrunch.com/2026/04/07/google-quietly-releases-an-offline-first-ai-dictation-app-on-ios/

**Publication Date:** April 7–8, 2026

**Keyword Match:** Edge AI and on-device models (#11)

**Summary:**
Google has quietly released an experimental iOS app called "Google AI Edge Eloquent" that performs AI-powered dictation entirely on-device using Gemma-based speech recognition models, with no internet connection required. Unlike standard speech-to-text tools that transcribe words literally, the app uses AI to clean up filler words, self-corrections, and verbal stumbles in real time — outputting polished, professional-quality prose. Users can optionally enable cloud mode to use Google's larger Gemini models for enhanced text cleanup, but the default experience is fully local and private. The app also offers text transformation modes (formal, key points, short, long) and can import specialized vocabulary from a user's Gmail account. An Android version with system-wide keyboard integration is reportedly in development.

**Key Data Points:**
- Built on Gemma ASR models, running fully on-device after initial download — no internet required in offline mode
- Automatically filters filler words ("um," "uh") and mid-sentence corrections in real time
- Transformation options: "Key points," "Formal," "Short," "Long" to reformat dictated text
- Optional cloud mode uses Gemini models for enhanced output quality
- Can import custom vocabulary, names, and jargon from the user's Gmail account
- App description: "engineered to bridge the gap between natural speech and professional, ready-to-use text"
- Android version referenced in App Store listing would enable system-wide dictation as a keyboard replacement
- Competes with Wispr Flow, SuperWhisper, and Willow — a market Google is now entering directly

**Why It Matters:**
On-device AI dictation is a practical productivity tool for any professional who types a lot — executives, consultants, writers, sales reps, analysts. The privacy-first offline model is significant: it removes the cloud dependency that makes many professionals hesitant to dictate sensitive information. Google entering this space directly signals that on-device AI inference is mature enough to handle production-quality tasks that previously required cloud compute, which has implications for enterprise privacy policies and mobile workflow design. For leaders evaluating AI productivity tools, this is a free, zero-setup entry point into voice-to-text workflows that their teams can start using immediately.
