## Summary
Anthropic announced at its Code with Claude developer conference on May 6 that it has signed a deal with SpaceX to access the full compute capacity of the Colossus 1 supercomputer in Memphis, Tennessee — more than 300 megawatts and approximately 220,000 NVIDIA GPUs. The deal is a direct response to exploding demand for Claude Code, which has been plagued by rate limits and outages as developers shifted from chat-based to multi-agent workflows. Anthropic immediately doubled Claude Code's five-hour usage limits for Pro and Max subscribers, removed peak-hours limit reductions, and raised Opus API limits. The partnership is notable because Musk had publicly attacked Anthropic in February 2026, calling the company "evil" — he reversed course after spending time with Anthropic leadership ahead of the deal. The announcement signals that compute access is now a decisive competitive variable: Anthropic's annualized revenue run rate has surpassed OpenAI's ($30B vs $24B), driven primarily by enterprise agentic adoption.

## Key Data Points
- 300+ megawatts of new compute capacity unlocked via SpaceX Colossus 1

- Claude Code's 5-hour usage limits doubled for Pro and Max subscribers immediately
- Peak-hours limit reductions on Claude Code removed for Pro/Max users
- Anthropic annualized revenue run rate: $30B vs OpenAI's $24B
- Anthropic committed $200B to Google TPU/cloud services (reported the same day)
- Anthropic committed $100B+ over 10 years to Amazon infrastructure

- Developers are averaging at least 20 hours per week running Claude Code
- SpaceX (now merged with xAI as "SpaceXAI") built Colossus 1 in 122 days
- Demand driver: shift from single-agent chat tasks to multi-agent workflows consuming far more compute per session

## Why It Matters
For any founder, developer, or team lead currently using Claude Code or evaluating Anthropic's tools, this directly changes what they can access today — doubled session limits and no more peak-hours throttling. More broadly, it confirms the pattern: compute scarcity is now the operative constraint on AI tool availability, and the companies that solve supply will set the product pace. Anthropic's revenue surpassing OpenAI's is a signal that enterprise agentic adoption — not consumer chatbots — is where the real spend is moving. SMBs who have been hitting rate-limit walls on Claude Code should revisit their usage plans; the bottleneck just meaningfully loosened.
