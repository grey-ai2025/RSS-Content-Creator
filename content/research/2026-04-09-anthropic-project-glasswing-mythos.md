# Anthropic keeps new AI model private after it finds thousands of external vulnerabilities

**Source URL:** https://www.artificialintelligence-news.com/news/anthropic-keeps-new-ai-model-private-after-it-finds-thousands-of-external-vulnerabilities/
**Publication Date:** April 9, 2026
**Keyword Match:** AI security and red-teaming, AI governance and safety, Agentic AI

## Summary

Anthropic has developed its most capable AI model — Claude Mythos Preview — and made the deliberate decision not to release it publicly. Instead of a standard product launch, the company quietly handed access to the organizations responsible for keeping the internet secure, under an initiative called Project Glasswing. The model autonomously identified thousands of cybersecurity vulnerabilities across every major operating system and web browser, including a 27-year-old OpenBSD bug and a 17-year-old remote code execution flaw in FreeBSD that allows unauthenticated internet access to servers. The 40+ organization coalition — including Apple, Google, AWS, Microsoft, Nvidia, CrowdStrike, Cisco, JPMorgan Chase, and the Linux Foundation — is now using Mythos to patch critical infrastructure before those vulnerabilities can be exploited. This marks the first time a frontier AI lab has deliberately withheld a general-capability model from public or commercial release on national security grounds.

## Key Data Points

- Claude Mythos Preview autonomously found vulnerabilities in "every major operating system and web browser"
- Specific finds include: a 27-year-old bug in OpenBSD; CVE-2026-4747, a 17-year-old remote code execution flaw in FreeBSD granting unauthenticated server access
- Model can "create exploits out of three, four, or sometimes five vulnerabilities in sequence" for sophisticated attack outcomes (Nicholas Carlini, Anthropic researcher)
- 40+ partner organizations in Project Glasswing, including AWS, Apple, Broadcom, Cisco, CrowdStrike, Google, JPMorgan Chase, Linux Foundation, Microsoft, Nvidia, and Palo Alto Networks
- Anthropic committed $100 million in usage credits for Mythos Preview
- $4 million in direct donations to open-source security organizations, including $2.5M to Alpha-Omega and OpenSSF, $1.5M to Apache Software Foundation
- Newton Cheng (Anthropic's Frontier Red Team Cyber Lead) warned that proliferation of Mythos "could be severe" for economies, public safety, and national security
- This is a preview model — general release timeline is not announced; the implication is it may never be broadly released in current form

## Why It Matters

For CISOs, security professionals, and enterprise technology leaders, Project Glasswing reframes what AI's role in cybersecurity can be. An AI model that can autonomously chain multiple zero-day vulnerabilities into sophisticated exploits — and find them across every major OS and browser — represents a fundamentally new category of security tool. But the story has a second, equally important layer for executives and board-level decision-makers: Anthropic has established the precedent that the most powerful AI models will be governed by controlled deployment, not open release. This is a direct challenge to every AI governance framework that assumes capability scales with accessibility. For organizations currently evaluating AI vendors or building internal AI security protocols, this changes the threat model and the competitive landscape simultaneously.
