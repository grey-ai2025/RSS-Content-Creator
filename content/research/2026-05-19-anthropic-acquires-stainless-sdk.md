# Anthropic Acquires the Dev Tools Startup Used by OpenAI, Google, and Cloudflare

**Source URL:** https://techcrunch.com/2026/05/18/anthropic-has-acquired-the-dev-tools-startup-used-by-openai-google-and-cloudflare/

**Publication Date:** May 18, 2026

**Keyword Match:** Model Context Protocol (MCP) and agent interoperability; AI agent proliferation problem; AI agents as digital coworkers

**Summary:**
Anthropic has acquired Stainless, a New York-based startup that automates the creation and maintenance of software development kits (SDKs) — the libraries developers use to connect their products to APIs. Stainless, founded in 2022 by former Stripe engineer Alex Rattray and backed by Sequoia Capital and Andreessen Horowitz, was the infrastructure quietly powering SDK generation for OpenAI, Google, Cloudflare, Replicate, and Runway. The deal is valued at over $300 million. Anthropic will wind down all hosted Stainless products, and existing customers retain rights to previously generated SDKs but will no longer access the platform going forward. The move consolidates a critical piece of the AI agent connectivity stack inside Anthropic while simultaneously removing that same tool from its biggest competitors.

**Key Data Points:**
- Deal value: over $300 million (reported by The Information)
- Stainless generated every official Anthropic SDK since the earliest days of the Claude API
- Prior Stainless customers include OpenAI, Google, Cloudflare, Replicate, and Runway
- Stainless was founded in 2022 by Alex Rattray, former Stripe engineer
- Backed by Sequoia Capital and Andreessen Horowitz
- Anthropic is winding down all hosted Stainless products immediately
- Existing customers retain full rights to previously generated SDKs but lose ongoing platform access
- Stainless converts API specifications into production-ready SDKs in Python, TypeScript, Kotlin, Go, and Java, then auto-updates them as APIs change

**Why It Matters:**
For founders and SMB operators building products on top of AI APIs — or deploying AI agents that connect to external software — SDK quality and maintenance is an invisible but constant cost. Stainless eliminated the engineering hours required to keep SDKs synced with rapidly changing AI APIs. With Anthropic owning this infrastructure exclusively, teams that relied on Stainless for their integrations with other AI providers now face a gap. This also signals a broader strategic move: controlling the tooling layer is how Anthropic locks in developers and makes Claude the default API underneath enterprise agent stacks. For any team evaluating which AI platform to build on, this acquisition shifts the calculus — not because of model capability, but because of developer experience infrastructure.
