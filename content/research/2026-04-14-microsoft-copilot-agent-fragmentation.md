## Summary

Microsoft is building a fourth entry into its AI agent lineup — an OpenClaw-inspired, locally-running agent designed to integrate with Microsoft 365 Copilot for enterprise customers. The new agent, which The Information reported and Microsoft confirmed, joins three existing agentic tools: Copilot Cowork (launched March 2026, acts inside M365 apps, powered by Claude via Anthropic partnership), Copilot Tasks (launched February 2026 preview, geared toward prosumers for email/travel/appointments), and now an unnamed "Claw" agent that would run locally and operate continuously on multi-step tasks over long periods. The agent is expected to be showcased at Microsoft Build in June. Unlike OpenClaw — the open-source tool whose viral adoption was driven by Mac Mini users and which has a documented security vulnerability history — Microsoft's version promises enterprise-grade security controls. The proliferation of named agents in rapid succession reflects a broader pattern: Microsoft is racing to own enterprise AI productivity before OpenAI's platform strategy (outlined in its leaked memo, same day) locks in direct enterprise relationships that bypass Microsoft's reseller position.

## Key Data Points

- Microsoft's current agentic AI lineup: **Copilot Cowork** (M365 apps, cloud-based, Claude-powered), **Copilot Tasks** (cross-app tasks including outside M365, cloud-based), **new Claw agent** (locally-running, always-on, multi-step enterprise tasks)
- The new agent is designed to run **"autonomously around the clock"** completing tasks on behalf of enterprise users — confirmed by Microsoft VP Omar Shahine
- **Security contrast**: OpenClaw's open-source version has had documented vulnerabilities including a remote admin access exploit; Microsoft's version promises enterprise security controls
- Microsoft partnered with **Anthropic's Claude** to power Copilot Cowork — making Claude the enterprise intelligence layer inside Microsoft's own productivity suite
- **OpenClaw adoption signal**: Mac Mini computers surged in sales as the go-to hardware for running OpenClaw locally — Microsoft's locally-running agent directly targets this use case
- The new agent joins **Copilot Cowork** (cloud, deep M365 integration) and **Copilot Tasks** (cloud, broader prosumer tasks) — creating three overlapping agent products with distinct but unclear boundaries
- Expected public reveal: **Microsoft Build conference, June 2026**
- OpenAI's simultaneous leaked memo (April 13) warns enterprises against "single-product companies" and positions Frontier as the default enterprise agent platform — a direct competitive threat to Microsoft's Copilot ecosystem

## Why It Matters

For every operator or team lead whose company runs on Microsoft 365 — which covers the majority of SMBs globally — this story has an immediate practical dimension. Three AI agents with overlapping capabilities and no clear "use Cowork when X, use Tasks when Y, use Claw when Z" guidance is a real pain point. The hidden story inside this fragmentation is Microsoft's competitive fear: OpenAI's leaked memo (same day) explicitly calls out Amazon as its distribution play and describes a strategy to make OpenAI "operating infrastructure" that bypasses Microsoft's reseller layer. Microsoft's aggressive agent expansion is a defensive move — if OpenAI wins direct enterprise relationships, Microsoft loses its AI revenue multiplier. For the SMB operator: the relevant near-term decision is whether to standardize on Copilot (and navigate the fragmentation) or wait until the agent landscape clarifies in H2 2026. The Build conference in June is the most likely moment for Microsoft to rationalize its agent product story.
