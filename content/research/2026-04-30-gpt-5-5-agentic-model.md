# GPT-5.5: OpenAI's Most Capable Agentic AI Model Yet — At Double the Price

**Source URL:** https://www.artificialintelligence-news.com/news/gpt-5-5-is-openais-most-capable-agentic-ai-model-yet-at-twice-the-api-price/

**Publication Date:** April 29, 2026

**Keyword Match:** agentic AI; large reasoning models (LRMs); vibe coding

## Summary

OpenAI launched GPT-5.5 on April 23, framing it as "a new class of intelligence for real work and powering agents." The model is the first retrained base model since GPT-4.5, co-designed with NVIDIA's GB200 and GB300 NVL72 systems to handle long-context agentic workflows. Benchmark scores show significant jumps over GPT-5.4 — particularly in command-line workflows, long-context retrieval, and web-browsing tasks. API pricing doubles versus GPT-5.4 (to $5/$30 per million tokens), though OpenAI claims 20% lower effective cost per task due to improved token efficiency. The model rolls out across Plus, Pro, Business, and Enterprise ChatGPT tiers, as well as Codex.

## Key Data Points

- Terminal-Bench 2.0 (command-line): GPT-5.5 scores 82.7% vs GPT-5.4's 75.1%
- SWE-Bench Pro (GitHub issue resolution): 58.6% (first-attempt resolution rate)
- MRCR v2 at 1M tokens: 74.0% vs GPT-5.4's 36.6% — a 2x improvement in long-context recall
- BrowseComp (web-browsing): 90.1% for GPT-5.5 Pro
- Standard API price: $5/M input tokens, $30/M output — double GPT-5.4 rates
- GPT-5.5 Pro: $30/$180 per million tokens
- OpenAI claims 20% lower effective cost per completed task due to token efficiency
- Greg Brockman: "a real step forward towards the kind of computing that we expect in the future"
- Available in ChatGPT Plus, Pro, Business, Enterprise, and via Codex

## Why It Matters

GPT-5.5 is the clearest signal yet that OpenAI is optimizing for agentic use cases — multi-step tasks, long-context document work, autonomous coding — rather than simple prompt-and-response. For founders and team leads evaluating AI tools, the doubling of API prices is a real decision point: the model is more capable, but cost structures need to be re-evaluated for anyone building products or workflows on top of OpenAI's API. The long-context retrieval improvement (36.6% to 74.0% at 1 million tokens) is particularly relevant for anyone using AI to process large documents, legal agreements, financial reports, or customer databases. The question for SMB operators is not just "is it better?" but "is it 2x better for my use case?"
