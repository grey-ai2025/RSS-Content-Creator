## Summary

Microsoft is building a fourth entry into its AI agent lineup — an OpenClaw-inspired, locally-running agent designed to integrate with Microsoft 365 Copilot for enterprise customers. The new agent, which The Information reported and Microsoft confirmed, joins three existing agentic tools: Copilot Cowork (launched March 2026, acts inside M365 apps, powered by Claude via Anthropic partnership), Copilot Tasks (launched February 2026 preview, geared toward prosumers for email/travel/appointments), and now an unnamed "Claw" agent that would run locally and operate continuously on multi-step tasks over long periods. The agent is expected to be showcased at Microsoft Build in June. Unlike OpenClaw — the open-source tool whose viral adoption was driven by Mac Mini users and which has a documented security vulnerability history — Microsoft's version promises enterprise-grade security controls. The proliferation of named agents in rapid succession reflects a broader pattern: Microsoft is racing to own enterprise AI productivity before OpenAI's platform strategy (outlined in its leaked memo, same day) locks in direct enterprise relationships that bypass Microsoft's reseller position.
