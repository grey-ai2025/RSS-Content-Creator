**Summary:**
Google has quietly released an experimental iOS app called "Google AI Edge Eloquent" that performs AI-powered dictation entirely on-device using Gemma-based speech recognition models, with no internet connection required. Unlike standard speech-to-text tools that transcribe words literally, the app uses AI to clean up filler words, self-corrections, and verbal stumbles in real time — outputting polished, professional-quality prose. Users can optionally enable cloud mode to use Google's larger Gemini models for enhanced text cleanup, but the default experience is fully local and private. The app also offers text transformation modes (formal, key points, short, long) and can import specialized vocabulary from a user's Gmail account. An Android version with system-wide keyboard integration is reportedly in development.

- Optional cloud mode uses Gemini models for enhanced output quality
- Can import custom vocabulary, names, and jargon from the user's Gmail account
- App description: "engineered to bridge the gap between natural speech and professional, ready-to-use text"
- Android version referenced in App Store listing would enable system-wide dictation as a keyboard replacement
- Competes with Wispr Flow, SuperWhisper, and Willow — a market Google is now entering directly
